# XO (Tic-Tac-Toe) Game

A console-based two-player XO game written in C++.

## Features
- 3x3 board displayed in the console
- Two players take turns (X and O)
- Win and draw detection
- Input validation for invalid or already-taken positions

## Concepts Used
- Object-Oriented Programming (classes for the board and the game)
- 2D arrays
- Loops and conditionals

## How to Run
1. Clone the repository:
  
   git clone https://github.com/azabyoudsef-wq/Xo-Game.git
   
2. Compile:
  
   g++ main.cpp -o xo
   
3. Run:
  
   ./xo
